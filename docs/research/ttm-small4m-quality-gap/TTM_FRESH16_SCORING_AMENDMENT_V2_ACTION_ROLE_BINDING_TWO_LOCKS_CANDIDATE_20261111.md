## 2. P1 — Operational adherence definition (prospective change)

Adherence is scored **only from the newly generated bytes**, using the original prompt to interpret context. The prompt itself supplies no credit. Prompt echo, isolated actor/object names, or copying the intervention is not a continuation.

### 2.1 Event predicate and role test

An **observable newly generated event** requires: (a) a recognizable actor or implicit continuing actor; (b) a predicate expressing an **actual** action, outcome or state transition, not just the intent already stated by the prompt; and (c) a concrete argument, result or fact-condition relevant to the ongoing goal. A complete sentence is **not required**; grammatical quality is described separately. The judge must be able to quote a **span of generated text only** that supplies a new realized event beyond the dangling prompt slot.

When the prompt already contains the verb or the start of the action (e.g., "went to"/"look inside the"), filling a missing object/recipient/place alone **does not count** as a newly realized event: that action/goal was already cued. The generated continuation must make something **happen next** (an enacted act, consequence or goal progress), not merely restate where the character intended to go. Conversely, if an actual new event is expressed by a clause split across the prompt boundary, judge the **newly supplied predicate/result plus original context together**, but require newly generated text to provide a new assertion beyond lexical completion of the prompted action. If the evidence is unclear, do not grant ≥2.

**Rubric V2 candidates (unchanged score range, new operational rule):**

| Score | Prospective operational decision |
|---|---|
| 0 | Empty/EOS immediately; no interpretable continuation, or explicit hard contradiction with frozen changed fact/central goal |
| 1 | Interpretable fragment or correct cloze/role word(s) only, paraphrase/echo, prompted intent merely restated; **no observable new event** |
| 2 | At least one generated **new event or consequence** whose participant/role/condition is grounded in the intervention and goal; no central contradiction; minor lapses allowed |
| 3 | Grounded new event plus coherent plot progress, correct actor/object/condition/goal maintained, no direct contradiction |

**Cloze-only cap:** ≤1, even if the missing word matches the expected fact. Merely completing a syntactically unfinished sentence without a new observable event is still ≤1. EOS early after genuine event is evaluated on what was generated; EOS before such event is ≤1 (empty → 0). A valid but short fragment with a new event can reach 2; length, fluency, or repetition alone never adds points. If generated text quotes the prompt and then adds a new event, score solely on the new event; copied words provide no credit.

**Evidence fields:** `generated_event_text_span`, `new_event_predicate`, `new_event_arguments`, `prompt_only_predicate_or_intent`, `cloze_only`, `EOS_or_empty`, `hard_contradiction`, `reason_for_score`. A score ≥2 **must** carry an evidence span from the generated continuation, and a statement why it is an event rather than a dangling-slot completion.

## 3. P2/F05 — H2: lexical change vs semantic role binding vs fact-dependent action

H2 is a contrast **of event meaning and its intervention-dependent arguments**, not a test that two outputs must use different verbs. Compare tuples:

`event=(actor, predicate/action, patient, recipient, source, destination, location, condition, goal-relevant outcome)`

A different tuple is *sufficient only if* the differing component is causally licensed by the changed prompt fact, appears in an observable **new generated event**, is not just an isolated copied word, and both individually locked adherence scores are ≥2.

| Category of observed difference | H2 pair decision | Operational rule |
|---|---|---|
| `LEXICAL_SWAP_ONLY` | **0** | Changed nouns/adjectives/one-slot strings with no evidence of newly realized, intervention-grounded event |
| `SEMANTIC_ROLE_BINDING` | **May be 1** | Same predicate can legitimately bind **different actor/holder/patient/location/recipient** according to A/B, and both completions narrate an observable goal-relevant event using that role; intervention makes the bound role meaningful |
| `FACT_CONDITIONED_ACTION` | **May be 1** | A/B produce differently licensed remedial actions, state changes or goal outcomes tied to changed fact, with new generated events |
| `GENERIC_COMMON_VALID` | **0**, flag | Both may be individually valid, but same generic event is compatible with both facts; **not evidence of fact-conditioned contrast** and not automatically model error |
| `UNRELATED_DIVERGENCE` | **0** | Different events occur, but distinction has no defensible link to the actual A/B intervention |
| `CONTRADICTORY_OR_UNINTERPRETABLE` | **0** | One variant's event contradicts changed fact or its adherence is below 2 |

**Important:** Do not require a different surface verb for CP01/CP02/CP05/CP06; correct role/recipient/target/location binding can qualify. Do **not** award H2 just because the generated sequence repeats `box` versus `bag`, `Mom` versus `Dad`, color names, or animal names. A genuinely enacted action involving the right role in each variant, with meaningful intervention-dependent event tuples, **can** be H2=1 despite identical syntactic templates. A new object name not used in an observable event is not enough.

**H2=1 exact rule:** All must hold:
1. Both Stage-1 locked `adherence_0_3 >= 2`.
2. Stage-2 adjudicator identifies an observable **new event** in each output and quotes its generated-only evidence span.
3. There is an **intervention-dependent difference** in the event predicate, relevant semantic role/argument, state-transition or outcome, directly attributable to the pair's changed fact.
4. Neither output contains a direct contradiction of its own changed fact.
5. The contrast exceeds a bare lexical swap and would cease to be appropriately grounded if A/B conditions were exchanged (explicit **swap countercheck**). If swapping conditions would still make both events equally appropriate, contrast is non-diagnostic → H2=0.

For fixed CP01–CP08, pre-execution classification by target semantic mechanism (NOT newly authored prompts): CP01 location/source; CP02 recipient/holder; CP03 causal remedy; CP04 door-access condition; CP05 constrained choice/target; CP06 sick-animal/patient-role; CP07 prior obligation/action; CP08 condition-appropriate warming. This grouping is **interpretive only**, and does not change frozen 4 group labels, H2 denominator or required pass in each group.

**CP04 and CP08 common-valid replies:** A generic behavior that can be correct under both interventions is not proof of ignoring the fact, but is **H2=0** if no observable intervention-dependent contrast. Record `PAIR_NON_DIAGNOSTIC_COMMON_VALID` as a limitation rather than a model-error label. Do not drop the pair from H2 denominator or introduce an alternative adjusted H2.

**Ambiguity:** If a role-binding contrast or swap countercheck cannot be justified from the generated text, H2=0 with `NOT_OBSERVED_CONTRAST` or `AMBIGUOUS_NON_DIAGNOSTIC`; note this is a measurement outcome, not a general finding of incapability. If the **scoring procedure itself** cannot be applied consistently, stop with `HOLD_SCORING_DISPUTE`, **not** arbitrary H2=0.
